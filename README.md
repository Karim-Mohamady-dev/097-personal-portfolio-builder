# منشئ الملف الشخصي

إدخال الملف الشخصي والمشاريع والمهارات بمستويات والخبرات، مع معاينة حية تتحدث أثناء الكتابة، وثلاث سمات وأربعة ألوان تمييز، وطباعة أو حفظ PDF من المتصفح. كل البيانات محفوظة في localStorage.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## اللغات

عربي (RTL) وإنجليزي (LTR) مع مبدّل لغة ظاهر، والتفضيل محفوظ في localStorage. ملفات الترجمة في `locales/en/common.json` و`locales/ar/common.json`.

## التقنية

React + TypeScript + Vite + Tailwind CSS. أيقونات Phosphor.
